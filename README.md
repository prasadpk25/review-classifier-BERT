# Review Classifier using BERT

Fine-tuned a BERT model for sentiment and review classification using HuggingFace Transformers.

## What it does
- Classifies text reviews as positive or negative
- Fine-tuned on real-world review data
- Covers full pipeline: tokenization, training, and evaluation

## Tech Stack
- Python · BERT · HuggingFace Transformers · PyTorch · Jupyter

## How to Run
1. Open the notebook in Jupyter or Google Colab
2. Install dependencies: `pip install transformers torch`
3. Run all cells in order
